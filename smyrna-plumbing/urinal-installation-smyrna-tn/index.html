    Commercial Urinal Installation in Smyrna

    Offices and restaurants want urinals that survive heavy use. Each unit goes on a carrier with new gaskets and stainless bolts, paired with a matched Sloan or Zurn valve. Partitions get spaced to code. Most codes want 15 inches from centerline to the side.

    Waterless Urinal Upgrades in Smyrna

    Switching to waterless is mostly a fixture swap. We remove the flush valve, cap the supply and set the waterless bowl on the same carrier. Many jurisdictions want a capped supply kept for later. That allows a future change back.

    Sensor Urinal Installation in Smyrna, TN

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Expect years between battery changes. Hardwired units need an electrician first.

    Urinal Installation Cost Factors in Smyrna, TN

    Carrier work is the biggest cost swing. A replacement on an existing carrier with good supply and drain lines costs far less than a new install that needs a carrier, a new 2 inch drain and a 3/4 inch supply run through finished walls. Touchless valves cost more than manual. We itemize each piece.

    Flushometer Urinal Installation in Smyrna

    Manual flushometers are still the most common setup. We install Sloan Royal or Zurn AquaFlush valves on a 3/4 inch supply, adjust the control stop for proper flow, and set the vacuum breaker the right distance above the bowl so it protects the drinking water. Handles can go left or right. ADA units need the handle within reach.

    American Standard and Kohler Urinal Installation in Smyrna

    American Standard and Kohler make the china we install most. Models like the Washbrook and the Bardon come in versions from 0.125 to 1.0 gallons per flush, and each one needs a flush valve matched to that rating or the bowl will either splash or not rinse clean. Matching is simple with the spec sheet. We order both together.
