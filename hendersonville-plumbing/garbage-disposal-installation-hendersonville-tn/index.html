    An air button on the sink deck or counter turns the disposal on. The button pushes air through a tube to a control box in the cabinet, which keeps electricity away from the button and avoids a new wall switch. They are common on islands.

    Disposal Upgrades in Hendersonville, TN

    Stepping up from an old 1/3 HP unit to a quieter model is a common request. Corroded drain arms get swapped. Galvanized arms rust from the inside.

    Disposal Rough-In for New Construction in Hendersonville

    At rough-in we set the drain height and the outlet location before the cabinets go in.     First-Time Disposal Installation in Hendersonville
