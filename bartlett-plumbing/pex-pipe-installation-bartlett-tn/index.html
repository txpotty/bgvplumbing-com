    PEX-A Expansion Fitting Systems in Bartlett, TN

    PEX-A, such as Uponor, uses an expansion tool to stretch the pipe and a ring over the fitting, which then shrinks back into a tight seal.     Manifold and Home-Run PEX Layouts in Bartlett, TN

    A manifold system sends a dedicated line from a central hub to each fixture, much like a breaker panel for water.
