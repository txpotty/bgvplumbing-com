    Office and Restaurant Urinal Installation in Johnson City

    Restaurant restrooms see a lot of traffic in short bursts. Busy bars can see hundreds of flushes a night, so we install valves that recover fast and carriers that stay tight. Vandal-resistant valves are available. Night installs keep you open.

    Residential Urinal Plumbing in Johnson City, TN

    Home urinals use the same rules as commercial ones. Expect a 2 inch drain, a built-in trap, a vent and a supply sized to the flush valve. Permit rules apply too. We check that first.

    Flush Valve Urinal Installation in Johnson City, TN

    Flush valve urinals are the commercial standard. Tankless flushometers deliver a set volume from a 3/4 inch line and recover instantly for the next user. The volume matches the fixture rating. Wrong settings stain bowls.

    Sensor Urinal Installation in Johnson City, TN

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Batteries last a few years. Hardwired units need an electrician first.
